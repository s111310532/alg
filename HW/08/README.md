旅行推銷員問題

給定一組城市以及每兩座城市之間的移動距離，推銷員必須從某一城市出發，走訪每個城市恰好一次，最後回到原始起點，目標是找出總行經距離最短的封閉路徑。

一、方法

1.改良法

原理:隨機產生一條閉合路徑，再疊代中隨機挑選兩個城市對調，如果路徑縮短保留路徑，反之繼續嘗試。

2.爬山演算法

原理:採用系統化的局部搜索，利用2-OPT，他會窮舉檢查任意剪開兩條邊並交叉反向接回的所有可能，發現翻轉某段能縮減路徑並會採納新結果，直至無法縮短。

3.模擬退火法

原理:模擬金屬冷卻退火的過程。遇到更短路徑時一定接受外，當擾動產生更差的路徑時，仍保留以一定機率(波茲曼機率 P=e^(−ΔE/T))採納該劣解的彈性。初期高溫時廣泛亂走以跳脫局部陷阱，隨溫度降低逐漸收斂成嚴格爬山。

4.梯度下降法

原理:透過建立連續機率矩陣，估算每個時間步長各城市出現的期望座標，構造一個可微的連續環路長度損失函數，並利用數值梯度更新權重，最後再將機率最高者離散化投影回實際路徑。

5.貪婪演算法

原理:從起點出發，每次都在尚未拜訪的城市中挑選距離目前位置最近的城市走，直到所有城市走完，最後強制直接連回起點。

二、成果總結

模擬退火法>爬山演算法>貪婪演篹法>梯度下降法>改良法

成因1:爬山演算法容易被困在鄰域的局部死角，而模擬退火法允許在關鍵時刻暫時變差，這讓它成功跳過了局部的封閉阻礙，尋找到更接近全域最佳解的路徑。

成因2:2-Opt 能針對性地消除所有相交路段，因此幾步之內就能理出漂亮的幾何環線。若遇到更深層的全局排列瓶頸，就無法再進一步優化。

成因3:起初每一步都挑最近的點，局部效率很高；但因為缺乏全局規劃，當接近結尾時，剩下的未訪城市往往散落在邊界或遠處，最後不得不走長距離回收殘餘節點並返回出發點，導致末端成本大幅膨脹。

成因4:離散約束在連續鬆弛化求導時難以保證絕對嚴格滿足，在最後一步將連續機率硬性解碼成離散路徑時，容易產生局部的次優錯位與殘留交叉。

成因5:單純隨機交換兩個點，很難在龐大的排列空間中解開兩個路段交叉的幾何結構。當路徑打結時，必須同時調動多個點或反轉連續子路徑才能解開，隨機單點交換很難碰巧觸發這種修正，因此收斂效率低且極易停留在很差的解。

三、優缺點

1.改良法

優點:程式碼簡短。

缺點:盲目搜尋，缺乏針對拓撲交叉的局部優化機制。

2.爬山演算法

優點:運算速度快，2-Opt能快速消除所有平面交叉。

缺點:無法回頭，極易停在局部最優解。

3.模擬退火法

優點:求解品質最佳，具備跳出局部最優的能力。

缺點:需調整降溫曲線參數，耗費較多運算步數。

4.梯度下降法

優點:可結合神經網路或連續最佳化框架端到端求解。

缺點:連續空間解投影回離散排列時易產生精度損失。

5.貪婪演算法

優點:構造速度極快(O(N^2))，不需多次疊代。

缺點:後期收尾成本不可控，無法動態調整前期錯誤。

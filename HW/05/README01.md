遞迴解法

1.先將上方 n-1 個盤子從 A 移到 B

2.將第 n 個盤子直接從 A 移到 C

3.最後將那 n-1 個盤子從 B 移到 C

非遞迴解法

利用規律迭代法

n 個盤子，總移動步數必為 2^n-1

1.若 n 為偶數：目標柱 C 與輔助柱 B 在邏輯順序上調換，即輪替順序為 A 移到 B 移到 C 移到 A。

2.若 n 為奇數：輪替順序為 A 移到 C 移到 B 移到 A。

3.總共進行 2^n - 1 次移動，依據當前步數 ：

i (mod) 3 == 1：在「來源柱」與「目標柱」之間進行合法移動。

i (mod) 3 == 2：在「來源柱」與「輔助柱」之間進行合法移動。

i (mod) 3 == 0：在「輔助柱」與「目標柱」之間進行合法移動。

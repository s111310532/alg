不動點跌代

透過不斷代入函數來逼近解的方法，要滿足∣g′(x)∣<1才會收斂到不動點，不然∣g′(x)∣>1迭代值會越跑越遠，導致發散無法得到解答。

方程式 f(x)=0，我們可以透過代數變形，把它改寫成等價的形式： x=g(x) 此時，能讓等式左右兩邊相等的數值 p（即 g(p)=p）就稱為函數 g(x) 的不動點（Fixed Point）。而這個不動點，剛好就是原方程式 f(x)=0 的根。

設x^2 −2x+1=0為範例，可分解為(x-1)^2=0，為重根。

不動點為x=(x^2+1)/2

g(x)=(x^2+1)/2，g′(x)=x

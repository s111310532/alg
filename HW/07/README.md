一.動態規劃解法

建立在巴斯卡三角形的遞迴上:C(n,k)=C(n−1,k−1)+C(n−1,k)

選第n個數:剩下n-1個數只要選k-1個數。

不選第n個數:剩下n-1個數要選k個數。

當k=0或k=n時，C(n,k)=1。

當k>n時，C(n,k)=0。

複雜度分析 

1.時間複雜度：O(n⋅k) 

雙層迴圈分別走訪n與k，每次執行常數時間的加法。 

2.空間複雜度： 

未最佳化（完整巴斯卡表）：O(n⋅k)

滾動陣列空間最佳化：O(k)

二.非動態規劃解法
​
採用交替乘除迭代:C(n,k)=n!/k!(n−k)!=​n×(n−1)×⋯×(n−k+1)/k×(k−1)×⋯×1=i= ∏ n−k+i/i

數學上保證：連續i個整數的乘積必為i的倍數，因此每次除法運算皆能整除，不會產生浮點數精度損失。

利用對稱性C(n,k)=C(n,n−k)，先取k=min(k,n−k)，可最小化計算步數。

複雜度分析

1.時間複雜度：O(k)

只需要單一迴圈迭代k次，效率極高。

2.空間複雜度：O(1)

僅需常數個變數儲存累積結果與計數器。

三.兩者優缺

1.動態規劃:溢位風險低，較適合多點查詢。

2.非動態規劃:溢位風險較高，適合單點查詢。
